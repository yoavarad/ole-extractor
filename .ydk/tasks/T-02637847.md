## Description

ExcelExtractor.GetFirstLayerEmbedded (ExtractorOle/ExtractorOLE/Old/Excel/ExcelExtractor.cs) only scans workbookPart.Parts for embedded objects. OOXML doesn't allow ImagePart/EmbeddedObjectPart directly on WorkbookPart -- they must live on a WorksheetPart. Confirmed via SampleGenerator (T-5e9dbd18): xlsx files generated with embeddings correctly place them on WorksheetPart per the OOXML schema, but ExcelExtractor's current first-layer walk never finds them since it doesn't scan worksheet parts. Fix ExcelExtractor to also walk each WorksheetPart's parts for embedded objects/media, consistent with how docx/pptx first-layer embedding walks are wired (see T-29fbb7cf, T-c3f1ec05).
