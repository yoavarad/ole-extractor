## Description

Implement the open component for legacy .ppt: body/slide content converted in-process to .pptx via b2xtranslator (per ADR-004, not NPOI HSLFSlideShow -- no working entry point exists), then read through the existing DocumentFormat.OpenXml pptx path. FileMetadata is sourced from OLE SummaryInformation/DocumentSummaryInformation via NPOI's HPSF, independent of the body-conversion path. Registered through the DI dispatch registry.
